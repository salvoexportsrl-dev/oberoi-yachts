# Oberoi Yachts

Repository dedicato allo sviluppo e alla manutenzione del tema Shopify del sito https://oberoi.yachts/.

## Sicurezza e pubblicazione
- Il sito di produzione rimane gestito da Shopify.
- Non inserire credenziali, token, chiavi API, dati dei clienti o file `.env` nel repository.
- Le modifiche al tema devono essere verificate in anteprima prima della pubblicazione.
- Questo repository è separato dal progetto WORBEX.

## Stato
Repository inizializzato. Il codice del tema Shopify non è ancora stato importato né sincronizzato.
